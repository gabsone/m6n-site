Editor Markdown desktop

m6n m·arkdow·n

Scrivi in Markdown ed esporta in Word (DOCX) applicando il tuo template aziendale o personale. Tutto in locale, senza inviare contenuti a server esterni.

Scarica Codice sorgente

Caratteristiche

  • Editor e anteprima

    Syntax highlighting, anteprima live e un flusso di lavoro pensato per documenti lunghi.

  • Export DOCX templato

    Genera file Word coerenti con il tuo modello: stili, copertina e struttura sotto controllo.

  • Libreria template

    Organizza e riusa i template sul tuo computer, senza dipendenze cloud obbligatorie.

  • Tema chiaro / scuro

    Rispetta le preferenze di sistema o scegli il tema che preferisci.

  • Offline

    Nessuna telemetria nel core: i tuoi documenti restano sul dispositivo.

Tecnologie

L’applicazione desktop combina un frontend moderno e un backend Rust affidabile.

  • Tauri 2 — app nativa leggera
  • Svelte 5 — interfaccia reattiva
  • Rust — conversione Markdown → DOCX
  • CodeMirror 6 — editor

Prova m6n

Binari per Windows e macOS sono pubblicati nelle Release su GitHub. Per sviluppatori: clona il repository e segue le istruzioni nel README del progetto.
