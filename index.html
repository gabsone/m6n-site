Dal Markdown al Word con il tuo template

m6n è un editor Markdown che vive sul tuo computer: scrivi con anteprima live ed esporti DOCX allineato al modello aziendale o personale — senza passare da cloud obbligatori.

Come funziona

Tre passaggi, zero sorprese: il flusso che ti aspetti da uno strumento da scrivania.

  1. 1

    Scrivi in Markdown

    Editor con evidenziazione sintassi, ricerca e anteprima: resti concentrato sul contenuto.

  2. 2

    Scegli il template

    Associa un modello Word: titoli, stili e impaginazione seguono le regole del tuo DOCX.

  3. 3

    Esporta in DOCX

    Un clic e ottieni un file pronto da inviare, archiviare o revisionare in Word.

Per chi è m6n

Utile quando il Markdown è comodo ma il deliverable deve rispettare un modello Word.

  • Team e aziende

    Documenti interni, note e report che devono rispettare il template corporate.

  • Freelance e studi

    Proposte e relazioni: scrivi veloce, consegni in formato richiesto dal cliente.

  • Scuola e ricerca

    Appunti in Markdown, consegne o bozze in Word quando serve la forma ufficiale.

Funzionalità

Tutto ciò che serve per lavorare bene sul testo, senza dipendere da un browser.

  • ◇

    Editor e anteprima

    Syntax highlighting, anteprima live e flusso pensato anche per documenti lunghi.

  • ◇

    Export DOCX templato

    Word coerente con il tuo modello: struttura e stili sotto controllo.

  • ◇

    Libreria template

    Organizza e riusa i template in locale: nessun cloud obbligatorio.

  • ◇

    Tema chiaro / scuro

    Allineato al sistema o scelto manualmente, come preferisci lavorare.

  • ◇

    Privacy by design

    Nessuna telemetria nel core: i contenuti restano sulla tua macchina.

Stack tecnico

Un’app nativa leggera: interfaccia moderna e motore Rust per la conversione.

  • Tauri 2 App desktop cross-platform
  • Svelte 5 Interfaccia reattiva
  • Rust Markdown → DOCX
  • CodeMirror 6 Editor di testo

Pronto a provare m6n?

Binari per Windows e macOS sono nelle release su GitHub. Per compilare da sorgente segui il README del repository.
